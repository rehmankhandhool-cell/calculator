# Modern Calculator 🧮

A responsive and interactive calculator built using **HTML, CSS, and JavaScript** as part of my Frontend Web Development Internship.

The project provides a clean, modern user interface with essential arithmetic operations and interactive functionality. It was developed to strengthen my understanding of **frontend development, DOM manipulation, JavaScript event handling, responsive design, and user input validation**.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal number calculations
* 🧹 Clear calculator function
* ⌫ Delete/backspace functionality
* ⚠️ Division-by-zero error handling
* ⌨️ Keyboard support
* 📱 Responsive design for different screen sizes
* ✨ Interactive button hover and click effects
* ⚡ Real-time display updates

## 🛠️ Technologies Used

* **HTML5** — Structure and semantic elements
* **CSS3** — Responsive layout, styling, animations, and UI design
* **JavaScript (ES6)** — Calculator logic, DOM manipulation, event handling, and keyboard support
* **Visual Studio Code** — Development environment
* **Live Server** — Local development and testing

## 🎯 What I Learned

Through this project, I practiced:

* Building a user interface from scratch
* Connecting HTML, CSS, and JavaScript
* Working with DOM elements and events
* Handling user input
* Implementing arithmetic logic
* Managing edge cases and invalid input
* Adding keyboard interactions
* Creating responsive layouts
* Improving user experience with interactive UI effects

## 🚀 Project Purpose

This calculator was created as a practical project for my **Frontend Web Development Internship** to apply fundamental web development concepts and build hands-on experience with HTML, CSS, and JavaScript.

More improvements and features may be added as I continue developing my frontend skills.
